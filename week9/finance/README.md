<h2>C$50 Finance</h2>

<p>
  <h4>
    A web application built with Flask and SQLite that allows users to simulate buying and selling stocks.
  </h4>
</p>

<ul>
  <li>Allows users to register, log in, and manage a stock portfolio.</li>
  <li>Displays current stock holdings with live prices and total portfolio value.</li>
  <li>Enables users to buy and sell stocks.</li>
  <li>Shows a full transaction history with date and time.</li>
  <li>Includes a user profile page.</li>
  <li>Allows users to change their password (personal touch).</li>
</ul>
