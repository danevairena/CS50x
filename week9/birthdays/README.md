<h2>Birthdays</h2>

<p><h4>A web application built with Flask and SQLite that allows users to store and view birthdays.</h4></p>

<ul>
  <li>Displays all birthdays from the database in a table.</li>
  <li>Allows users to add new birthdays via an HTML form.</li>
  <li>Handles GET and POST requests on the <code>/</code> route.</li>
</ul>
